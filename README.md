# 💫 About Me:
I’m **Mohammad Asif Al Mahfuz**, a Computer Science and Engineering student at BRAC University, Bangladesh, with interests in AI, cybersecurity, and software engineering. My primary research focuses on continuous authentication using behavioral biometrics, alongside an AI-driven credit-scoring system for small businesses. I’m expanding my technical skills in RISC-V, deep learning, and compiler design, while exploring brain-computer interfaces and UX/product design. I’m passionate about research-driven problem-solving and open to collaborating on AI, machine learning, and security-focused projects.
